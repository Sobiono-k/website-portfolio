01 — projects

capstone

AICS Predictive Decision Support System

An end-to-end predictive platform. An LSTM forecasts demand over time, and a Random Forest with SHAP explainability classifies hotspots. Both feed a PHP/MySQL web app that turns historical assistance data into interpretable spatial and category projections.

It runs as microservices on Render and Aiven, with custom cURL timeout handling and database-backed fallbacks, so the dashboard keeps working during ML API delays or cold starts.

Kira Clo. Shop

A serverless e-commerce storefront with zero backend dependencies. Browser storage handles persistent cart state and product sizing, while Netlify Forms or Formspree routes checkout orders and newsletter signups straight to email without a database.

It includes a password-protected admin panel that connects to the Netlify API, letting store owners search orders, send one-click email confirmations, and export CSV records directly from the browser.
